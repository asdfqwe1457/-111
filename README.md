## 小程序前端核心功能

### 1. 首页分类展示，多线路快速查找

首页支持切换出发城市，Banner 轮播投放旅游专题线路，板块划分**国内游、国际游、定制游**三大业务类型。线路支持按价格、热度综合排序筛选，线路卡片展示评分、浏览量、线路标题、图集预览，方便游客快速挑选合适行程。
同时内置景点专区，按景点类型分类：名胜古迹、亲子乐园、主题乐园等，覆盖海洋馆、地标景区、乐园等各类票务产品。

### 2. 景点 & 旅游线路详情页

景点 / 行程详情内展示开放时间、地理位置、优惠活动、套餐规格，区分成人票、儿童票、学生票等多种票种，不同票价独立设置；附带景区项目介绍、费用说明、行程须知。支持收藏、在线咨询客服，一键下单预定。

### 3. 旅行攻略板块

独立攻略栏目，分为旅行记、美食篇、拍照篇，商家可以发布游记、打卡攻略、出游指南，丰富平台内容，提升用户留存，吸引游客浏览种草。

### 4. 下单购票、支付、出行人管理

下单流程简洁，选择票种、出行人数，新增 / 选择出行人信息（姓名、身份证、手机号），对接微信支付完成付款。订单区分景点订单、旅游订单，支持待付款、待使用、已使用、退款等状态管理，用户在个人中心随时查看订单。

### 5. 分销推广佣金体系（盈利拓客核心）

自带分销裂变功能，用户可以邀请好友注册下单，自动计算推广佣金。个人中心内置**我的佣金**页面，清晰展示可提现金额、冻结佣金、佣金明细，支持佣金申请提现，适合旅行社业务员、代理推广卖票、分销线路，低成本拓客。

### 6. 个人中心配套模块

优惠券、收藏、消息、景点订单、旅游订单统一管理；包含出行人管理、邀请好友、客服入口、常见问题、隐私协议等功能，满足游客自助操作需求。![Uploading 93607eeddda6a2c1203b4567f8a6444b.png…]()
